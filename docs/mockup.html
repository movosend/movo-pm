Traer datos de Linear

El navegador consulta la API GraphQL de Linear directamente. La clave no viaja a ningún otro lado, pero tampoco queda oculta: usá este modo en tu máquina, no en una página publicada.

Traer los datos actualiza el grafo pero no las decisiones: ese bloque lo escribe el análisis. Si el navegador bloquea la consulta por CORS, usá linear-snapshot.mjs y cargá acá el JSON que genera.
