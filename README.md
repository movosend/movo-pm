# Movo PM

Herramienta interna para la planning quincenal del equipo de Movo: una lente sobre el ciclo activo de Linear (bloqueos, cadena crítica, sub-issues varadas, análisis asistido por Claude), con edición puntual de assignee, status y ciclo desde el panel lateral. No reemplaza a Linear, que sigue siendo la fuente de verdad. Uso exclusivo para devs de Movo.
